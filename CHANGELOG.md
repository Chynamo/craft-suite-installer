# Releases

## v1.4.0-preview.1

App cards now offer Install, Open or Update. A discreet menu offers another independent copy, folder access and remembered copy selection. Existing bulk selection, branded colours, original payloads and side-by-side update preservation remain.


## v1.3.1-preview.1

Palette-only refinement: charcoal, warm cream and red from the maintainer's established branding. Layout, original icons, status colours and installation behaviour unchanged.


## v1.3.0-preview.1

Original app-card design with actual Craft icons, category browsing, selected-card feedback and responsive two/three-column layout. Install/update engine and app versions unchanged.


## v1.2.1-preview.1

Recognisable software-workflow descriptions, clearer action/status text and versions moved into hover details. Release filenames include the three-part version. Install/update engine and app releases unchanged.


## v1.2.0-preview.1

App selection, offline installed-versus-bundled status, selected-app space estimate, backward-compatible receipts, remembered installation folder, add-later support, side-by-side updates and downgrade refusal. Existing apps/projects and older version folders are retained.


## v1.1.0-preview.1

First public community preview: twelve pinned Windows x64 releases, a graphical `Setup.exe`, folder selection, optional shortcuts, offline payloads, integrity checks and repeat-install protection. ArtCraft Studio and personal configurations are excluded. Tested locally; independent clean-PC testing is pending.
