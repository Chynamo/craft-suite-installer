CRAFT SUITE - GRAPHICAL OFFLINE SETUP

1. Copy this ZIP from USB to a Windows 10/11 x64 PC, then choose Extract All.
2. Open the extracted Craft-Suite-Windows-x64 folder.
3. Double-click Setup.exe.
4. Choose your installation folder and click Install all 12 apps.
5. When complete, click Open your apps or use the new shortcuts.

Keep the InstallerData folder alongside Setup.exe until installation finishes. All twelve app payloads are already included. No internet connection or administrator access is required. You do not need to open a command window or run a script manually. The graphical EXE uses built-in Windows PowerShell/.NET internally.

WHAT YOU GET
FilmCraft, EffectCraft, SoundCraft, PhotoCraft, LightCraft, VectorCraft, DesignCraft, CADCraft, PdfCraft, WordCraft, GridCraft and DeckCraft. Official unmodified releases by the ArtCraft team/community, with licences and required notices retained. This combined installer is a community bundle, not an official publisher installer. ArtCraft Studio is excluded.

Choose a normal writable folder, such as D:\Craft Suite. Approximately 1.3 GiB is installed; allow 3 GiB free when the ZIP, extracted setup and apps share a drive. Desktop and Start Menu shortcuts are optional. The installer preserves unrelated folders and existing intact versions, checks file integrity and creates a fresh LightCraft library. Personal projects/settings and recipient AI configurations are not included or configured automatically.

After a successful installation, the extracted setup folder can be removed or the ZIP kept on USB for another PC. Keep your own projects outside Apps. Repeat installation reuses intact app versions and retains added files; modified original files are refused instead of overwritten. Do not move the installed folder without recreating shortcuts.

Windows 10/11 x64 and built-in Windows PowerShell5.1/.NET are required. This EXE is not code-signed; managed policies or Windows reputation checks may flag an unsigned community installer. Other PCs/GPU drivers and every app feature have not been tested. Do not change your organisation's security policy to run it. Release URLs/checksums, app licences and asset notices are in InstallerData. Original publisher binaries/provenance are unchanged; no promise of undetectable authorship or publisher certification is made.
